Constraints for every reference plate, regardless of opening:

- Exactly one subject in frame (or, for a location plate, the environment with no incidental characters unless explicitly needed for scale).
- Plain or minimally styled backdrop — nothing that competes with the subject as the identity/appearance source.
- State the aspect ratio to match the target video's aspect ratio (default 16:9) so the plate composes cleanly if it needs a same-ratio crop.
- Use positive scene phrasing throughout — describe what should be in frame, not what to exclude, except when scoping a secondary input reference's role (e.g. "use the attached fabric swatch only for texture, not color").
- Do not include any internal planning ID (C1, C2, P##) as visible text anywhere in the prompt or expect it to render — describe the entity in plain language only.
- End with the fixed identity-descriptor sentence for this entity, stated exactly as it appears in every other prompt referencing them.
